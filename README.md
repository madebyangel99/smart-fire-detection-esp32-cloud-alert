## 🚀 Main Project — Group 3

### Smart Fire Detection and Alert System

**Prototipe Pendeteksi Kebakaran Otomatis Berbasis ESP32 dan Cloud Notification**

A prototype designed to detect potential fire conditions using an ESP32 microcontroller and sensor-based monitoring. The system is intended to provide automated detection and cloud-based notifications to support faster awareness of potential fire incidents.

#### 🎯 Project Objectives

- Develop an automatic fire detection prototype using ESP32.
- Integrate sensors for monitoring environmental conditions related to fire detection.
- Implement automated responses based on detected conditions.
- Enable cloud notification for remote alerts.
- Explore IoT-based monitoring and emergency alert systems.

#### ⚙️ Key Technologies

- **Microcontroller:** ESP32
- **Programming:** C/C++
- **Development Environment:** PlatformIO / Visual Studio Code
- **IoT Communication:** Wi-Fi
- **System Integration:** Sensors, firmware, cloud notification
